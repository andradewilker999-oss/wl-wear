W&L Wear — protótipo de loja virtual
====================================

Arquivos:
- index.html — estrutura da loja
- style.css — visual responsivo
- script.js — produtos, filtros, pesquisa e carrinho
- visual-referencia.png — referência visual gerada para o projeto

IMPORTANTE:
Este é um protótipo estático. O checkout ainda não processa pagamentos reais.
Para colocar a loja no ar, será necessário configurar domínio, hospedagem,
pagamento, estoque, frete e dados reais dos produtos.
